# Go Do event feed

`events.json` is the public list of upcoming events that the Go Do app shows, for Utah's Wasatch Front (Nephi to Tremonton) plus the Heber Valley. It is rebuilt automatically every 6 hours by the collector in the private `godo` repository. Please don't edit it by hand; changes get overwritten.

Live URL: https://jrcook3-godo.github.io/godo-feed/events.json
